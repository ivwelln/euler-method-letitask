## Краткое описание методов

**Классический явный Эйлер** (1-й порядок):
```
y_{k+1} = y_k + Δt · f(t_k, y_k)
```

**Комплексный 2-шаговый Эйлер** (2-й порядок) — между двумя соседними узлами
вещественной сетки делается пара комплексных шагов:
```
y* = y_k + (Δt/2 + iΔt/2) · f(t_k, y_k)
ỹ  = y* + (Δt/2 − iΔt/2) · f(t_k + Δt/2 + iΔt/2, y*)
y_{k+1} = Re(ỹ)
```
Сумма шагов даёт вещественное Δt, при этом численное решение совпадает
с рядом Тейлора точного решения вплоть до члена 2-го порядка.
