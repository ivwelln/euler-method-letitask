## Часть 1 — Одношаговые явные методы

### 1.1 Явный метод Эйлера

**Идея:** иди по касательной маленькими шагами.

**Формула:**
```
y_{k+1} = y_k + Δt · f(t_k, y_k)
```

**Геометрический смысл:**
```
Стоишь в точке (t_k, y_k).
Знаешь наклон кривой = f(t_k, y_k).
Делаешь шаг Δt по ПРЯМОЙ с этим наклоном.
```

**Нюансы:**
- 1 вычисление f на шаг
- Порядок 1: ошибка ~ Δt
- Уменьшил шаг в 10 раз → ошибка в 10 раз меньше
- Область устойчивости: круг |1+z|≤1, центр (−1,0), радиус 1
- НЕ подходит для жёстких задач (нужен очень маленький Δt)

**Когда использовать:**
- Нежёсткие задачи
- Когда важна простота реализации
- Для понимания идеи численных методов

---

### 1.2 Комплексный 2-шаговый метод Эйлера

**Идея:** два подшага через мнимую плоскость — зигзаг ±i.

**Формула:**
```
y* = y_k + (Δt/2 + iΔt/2) · f(t_k, y_k)
ỹ  = y* + (Δt/2 − iΔt/2) · f(t_k + Δt/2+iΔt/2, y*)
y_{k+1} = Re(ỹ)
```

**Почему 2-й порядок:**
```
Классический (2 шага): даёт 1 + Δt + Δt²/4  (коэф. 1/4)
Комплексный (2 шага):  даёт 1 + Δt + Δt²/2  (коэф. 1/2)
Точное eᵈᵗ:           даёт 1 + Δt + Δt²/2  (коэф. 1/2) ✓
```

**Нюансы:**
- 2 вычисления f на макрошаг (честное сравнение с классическим: 2 шага)
- Порядок 2: ошибка ~ Δt²
- Уменьшил шаг в 10 раз → ошибка в 100 раз меньше
- Область устойчивости: овал |1+z+z²/2|≤1, больше круга Эйлера
- Требует аналитического продолжения f в комплексную плоскость
- НЕ работает для функций без аналитического продолжения (max, if и т.д.)
- w₁ = ½+i/2 — единственный выбор для 2-го порядка

**Когда использовать:**
- Нежёсткие задачи где нужен 2-й порядок дёшево
- Особенно выгоден для комплексных ОДУ (нет доп. затрат)

---

### 1.3 Методы Рунге-Кутта

**Общая идея:** вычислить несколько наклонов внутри одного шага
и взять их взвешенное среднее. Высший порядок без дифференцирования f.

**Почему несколько наклонов дают высший порядок:**
```
f — это наклон кривой (первая производная y)
Разность f в двух точках ≈ изменение наклона = вторая производная
→ каждая новая точка даёт на одну производную больше
→ каждая новая производная = на один порядок выше
```

#### RK2 (метод средней точки)

**Формула:**
```
k₁ = f(t_k, y_k)                          ← наклон в начале
k₂ = f(t_k + Δt/2, y_k + Δt/2·k₁)        ← наклон в середине
y_{k+1} = y_k + Δt · k₂
```

**Вывод 2-го порядка:**
```
k₂ = f(t + Δt/2, y + Δt/2·k₁)
   = f + Δt/2·ḟ + O(Δt²)     ← разложение в ряд Тейлора

y_{k+1} = y + Δt·k₂
        = y + Δt·(f + Δt/2·ḟ)
        = y + Δt·f + Δt²/2·ḟ   ← совпадает с точным до Δt²!
```

**Нюансы:**
- 2 вычисления f на шаг
- Порядок 2
- Не требует дифференцирования f (в отличие от метода Тейлора)
- Работает для любого f

#### RK4 (классический)

**Формула:**
```
k₁ = f(t_k,         y_k)
k₂ = f(t_k + Δt/2,  y_k + Δt/2·k₁)
k₃ = f(t_k + Δt/2,  y_k + Δt/2·k₂)
k₄ = f(t_k + Δt,    y_k + Δt·k₃)

y_{k+1} = y_k + Δt/6·(k₁ + 2k₂ + 2k₃ + k₄)
```

**Веса 1, 2, 2, 1 (почему именно такие):**
```
k₁ — начало шага
k₂ — первая оценка середины
k₃ — уточнённая оценка середины
k₄ — конец шага

Веса: k₂ и k₃ важнее (дают лучшую оценку середины) → вес 2
      k₁ и k₄ крайние → вес 1
      Сумма: 1+2+2+1 = 6  → делим на 6
```

**Нюансы:**
- 4 вычисления f на шаг
- Порядок 4: ошибка ~ Δt⁴
- Уменьшил шаг в 10 раз → ошибка в 10000 раз меньше!
- Стандарт для большинства задач
- 5-й порядок требует уже 6 стадий (барьер Рунге-Кутта)
- Не A-устойчив (плохо для жёстких задач)

**Таблица Бутчера для RK4:**
```
 0  |  0    0    0    0
1/2 | 1/2   0    0    0
1/2 |  0   1/2   0    0
 1  |  0    0    1    0
────┼──────────────────
    | 1/6  1/3  1/3  1/6
```

Левый столбец c = моменты времени.
Матрица A = коэффициенты для вычисления k.
Нижняя строка b = веса усреднения.

#### Вложенные методы (RK45, RK23)

**Идея:** два метода разного порядка, использующие одни kᵢ.

**Зачем:**
```
y_{k+1}  = y_k + Δt·Σ bᵢkᵢ    ← порядок p   (основной)
ŷ_{k+1}  = y_k + Δt·Σ b̂ᵢkᵢ   ← порядок p+1 (вспомогательный)

Оценка локальной ошибки: err = |y_{k+1} - ŷ_{k+1}|
→ адаптивное управление шагом!
```

**RK45 (Дорманн-Принс):**
- 5 стадий, основной порядок 4, вспомогательный 5
- Стандарт в scipy.solve_ivp и MATLAB ode45
- Оценка ошибки «бесплатно» — используем уже вычисленные kᵢ

**Нюансы вложенных методов:**
- При err > tol: уменьшаем Δt, повторяем
- При err << tol: увеличиваем Δt (можно быстрее)
- Формула обновления шага: Δt_new = Δt·(tol/err)^(1/(p+1))

## Часть 2 — Многошаговые методы

### Ключевое отличие от одношаговых

```
Одношаговые: y_{k+1} зависит только от y_k
Многошаговые: y_{k+1} зависит от y_k, y_{k-1}, y_{k-2}, ...
```

Предыдущие точки уже посчитаны и хранятся → используем бесплатно.

**Идея:** аппроксимируем f(t,y) полиномом через несколько
прошлых значений, интегрируем этот полином аналитически.

**Важный нюанс (старт):**
Для AB2 нужны y_k и y_{k-1}. В начале есть только y₀!
→ Первые точки считают одношаговым методом (RK4).

```
Шаги 0-3:   RK4 (одношаговый)  → y₀, y₁, y₂, y₃
Шаги 4+:    AB4 (многошаговый) → y₄, y₅, y₆, ...
```

---

### 2.1 Adams-Bashforth (AB) — явный

**Идея:** полином строится по ПРОШЛЫМ значениям f.
Результат вычисляется явно (без решения уравнений).

**Формулы:**
```
AB1 (= Эйлер, порядок 1):
  y_{k+1} = y_k + Δt · f_k

AB2 (2 точки, порядок 2):
  y_{k+1} = y_k + Δt · (3/2·f_k − 1/2·f_{k-1})

AB3 (3 точки, порядок 3):
  y_{k+1} = y_k + Δt · (23/12·f_k − 16/12·f_{k-1} + 5/12·f_{k-2})

AB4 (4 точки, порядок 4):
  y_{k+1} = y_k + Δt · (55/24·f_k − 59/24·f_{k-1} + 37/24·f_{k-2} − 9/24·f_{k-3})
```

**Откуда коэффициенты (3/2 и −1/2 для AB2):**
```
Строим полином P(t) степени 1 через две точки (t_{k-1}, f_{k-1}) и (t_k, f_k):
P(t) = f_{k-1} + (f_k − f_{k-1})·(t − t_{k-1})/Δt

Интегрируем от t_k до t_{k+1}:
∫ P(t) dt = Δt·(3/2·f_k − 1/2·f_{k-1})
```

**Нюансы AB:**
- Только 1 вычисление f на шаг (независимо от порядка!)
- AB4: порядок 4 за 1 вычисление f (против 4 у RK4!)
- Нужна «история» (прошлые значения f)
- Нужен старт одношаговым методом
- Не A-устойчив → плохо для жёстких задач
- Чем больше точек → выше порядок, но нужно хранить больше истории

---

### 2.2 Adams-Moulton (AM) — неявный

**Идея:** полином строится включая f_{k+1} (новую точку).
→ нужно решать уравнение на каждом шаге (неявный).

**Формулы:**
```
AM1 (= неявный Эйлер, порядок 1):
  y_{k+1} = y_k + Δt · f_{k+1}

AM2 (= трапеция, 2 точки, порядок 2):
  y_{k+1} = y_k + Δt/2 · (f_k + f_{k+1})

AM3 (3 точки, порядок 3):
  y_{k+1} = y_k + Δt · (5/12·f_{k+1} + 8/12·f_k − 1/12·f_{k-1})

AM4 (4 точки, порядок 4):
  y_{k+1} = y_k + Δt · (9/24·f_{k+1} + 19/24·f_k − 5/24·f_{k-1} + 1/24·f_{k-2})
```

**Нюансы AM:**
- На один порядок точнее AB при том же числе точек
- f_{k+1} зависит от y_{k+1} → нужно решать уравнение
- AM1, AM2 — A-устойчивые
- Обычно используется в паре с AB (предиктор-корректор)

---

### 2.3 Предиктор-корректор (AB + AM)

**Идея:** AB делает быстрое грубое предсказание,
AM уточняет его без решения нелинейного уравнения.

**Алгоритм:**
```
Шаг 1 — Предиктор (AB2): быстрое приближение
  y*_{k+1} = y_k + Δt·(3/2·f_k − 1/2·f_{k-1})

Шаг 2 — вычисляем f в предсказанной точке:
  f*_{k+1} = f(t_{k+1}, y*_{k+1})

Шаг 3 — Корректор (AM2): уточнение
  y_{k+1} = y_k + Δt/2·(f*_{k+1} + f_k)
```

**Нюансы:**
- Итого 2 вычисления f на шаг
- Порядок выше чем AB или AM по отдельности
- Нет нелинейного уравнения (не нужен итерационный метод)
- Именно это используется в статьях Бутусова (semi-implicit)

## Часть 3 — Неявные методы и жёсткость

### 3.1 Жёсткость (stiffness)

**Определение:** система с собственными значениями
очень разного масштаба.

```
Пример: λ₁ = −1000, λ₂ = −1

λ₁ требует Δt ≤ 2/1000 = 0.002 для устойчивости явного Эйлера
λ₂ требовал бы Δt ≤ 2/1 = 2.0

Из-за λ₁ делаем в 1000 раз больше шагов чем нужно!
```

**Число жёсткости (stiffness ratio):**
```
S = |λ_max| / |λ_min|

S ≈ 1-10:     нежёсткая задача
S ≈ 10³-10⁶:  жёсткая задача
S > 10⁶:      очень жёсткая
```

**Примеры жёстких задач:**
- Химические реакции (разные скорости реакций)
- Электрические цепи (RC с разными постоянными времени)
- Механические системы (жёсткая пружина + медленное движение)

---

### 3.2 A-устойчивость

**Определение:** область устойчивости содержит
всю левую полуплоскость Re(z) < 0.

```
A-устойчивый метод:
  Re(λ) < 0  →  метод устойчив при ЛЮБОМ Δt
```

**Сравнение областей устойчивости:**
```
Явный Эйлер:   |1+z|≤1              → маленький круг → НЕ A-устойчив
Неявный Эйлер: |1/(1−z)|≤1          → вся левая полуплоскость → A-устойчив
RK4:           большой, но конечный → НЕ A-устойчив
AM2 (трапеция): вся левая плоскость → A-устойчив
BDF1-BDF6:     большие области      → A-устойчивы
```

---

### 3.3 BDF — Backward Differentiation Formula

**Идея:** аппроксимируем производную ẏ через разности
прошлых значений y (а не f как в Адамсе).

**Формулы:**
```
BDF1 (= неявный Эйлер, A-устойчив):
  y_{k+1} − y_k = Δt · f_{k+1}

BDF2 (порядок 2, A-устойчив):
  3/2·y_{k+1} − 2·y_k + 1/2·y_{k-1} = Δt · f_{k+1}

BDF3 (порядок 3, A-устойчив):
  11/6·y_{k+1} − 3·y_k + 3/2·y_{k-1} − 1/3·y_{k-2} = Δt · f_{k+1}

BDF4 (порядок 4, A-устойчив):
  25/12·y_{k+1} − 4·y_k + 3·y_{k-1} − 4/3·y_{k-2} + 1/4·y_{k-3} = Δt·f_{k+1}
```

**Откуда коэффициенты (3/2, −2, 1/2 для BDF2):**
```
Строим полином P(t) степени 2 через три точки:
(t_{k-1}, y_{k-1}), (t_k, y_k), (t_{k+1}, y_{k+1})

Берём производную P'(t_{k+1}) ≈ ẏ(t_{k+1}) = f_{k+1}:
P'(t_{k+1}) = (3/2·y_{k+1} − 2·y_k + 1/2·y_{k-1}) / Δt = f_{k+1}
```

**Нюансы BDF:**
- Неявный: нужно решать уравнение для y_{k+1}
- A-устойчив → можно брать большой Δt даже для жёстких задач
- Стандарт для жёстких систем в инженерии
- Python: `solve_ivp(f, method='BDF')`
- MATLAB: `ode15s`

**Чем BDF отличается от AM:**
```
AM: аппроксимирует ИНТЕГРАЛ f → использует значения f
BDF: аппроксимирует ПРОИЗВОДНУЮ ẏ → использует значения y
Результат похожий, но BDF имеет лучшую область устойчивости
```

## Часть 4 — Специальные методы

### 4.1 Симплектические методы

**Для каких задач:** гамильтоновы системы (маятник, планеты).

**Проблема обычных методов:**
```
Явный Эйлер:  фазовый объём РАСТЁТ → орбиты «раскручиваются»
Неявный Эйлер: фазовый объём УБЫВАЕТ → орбиты «схлопываются»
Ни то ни другое не соответствует физике!
```

**Метод Кромера (симплектический Эйлер):**
```
Явный Эйлер (НЕ симплектический):
  v_{k+1} = v_k + Δt·F(x_k)/m
  x_{k+1} = x_k + Δt·v_k         ← СТАРАЯ скорость

Метод Кромера (симплектический):
  v_{k+1} = v_k + Δt·F(x_k)/m
  x_{k+1} = x_k + Δt·v_{k+1}    ← НОВАЯ скорость!
```

Одна строчка отличается → метод становится симплектическим!

**Метод Верле:**
```
x_{k+1} = 2x_k − x_{k-1} + Δt²·a(x_k)
```

Симплектический, 2-й порядок, стандарт молекулярной динамики.

**Нюансы симплектических методов:**
- Сохраняют фазовый объём (det(J)=1)
- Не накапливают ошибку энергии на длинных временах
- Работают только для гамильтоновых систем
- Кромер и Верле — предшественники полунеявных методов Бутусова

---

### 4.2 Методы расщепления (splitting)

**Идея:** сложный оператор A+B разбить на простые части.

```
ẏ = (A + B)y

Метод Стрэнга (2-й порядок):
  y(Δt) ≈ e^{AΔt/2} · e^{BΔt} · e^{AΔt/2}

Симметричная схема → 2-й порядок автоматически
```

**Пример — уравнение переноса-диффузии:**
```
ẏ = −v·∇y + D·Δy
     ↑ перенос  ↑ диффузия

Расщепляем:
  Шаг 1: только перенос (быстрый метод)
  Шаг 2: только диффузия (неявным, т.к. жёсткая часть)
```

---

### 4.3 Экстраполяционные методы

**Идея:** считаем решение при нескольких шагах h, h/2, h/4...
и экстраполируем к h→0 (формула Ричардсона).

```
y_exact ≈ (2^p·y(h/2) − y(h)) / (2^p − 1)

Для p=1:
  y(h)   = y_exact + C·h
  y(h/2) = y_exact + C·h/2
  2·y(h/2) − y(h) = y_exact + O(h²)  ← порядок повысился!
```

Статья Бутусова math8060943 — ESIMM (экстраполяционный
полунеявный метод): экстраполяция применяется к
полунеявному базовому методу.

## Часть 6 — Адаптивное управление шагом

### Алгоритм

```
1. Считаем y_{k+1} методом порядка p
2. Считаем ŷ_{k+1} методом порядка p+1 (те же kᵢ)
3. err = ||y_{k+1} − ŷ_{k+1}||

4. Если err > tol  → шаг слишком большой
                    → Δt_new = Δt·(tol/err)^(1/(p+1))
                    → повторяем шаг с новым Δt

5. Если err < tol  → шаг слишком маленький (тратим впустую)
                    → увеличиваем Δt для следующего шага

6. Если err ≈ tol  → шаг оптимален → принимаем
```

### Формула обновления шага

```
Δt_new = Δt · (tol / err)^(1/(p+1))

Безопасность — умножаем на 0.9 чтобы не прыгать:
Δt_new = 0.9 · Δt · (tol / err)^(1/(p+1))
```

### Оценка ошибки без вложенного метода

Метод «шаг и полушаг» (таблица Рунге):
```
Считаем при Δt:   y_1
Считаем при Δt/2: y_2 (два шага)

Оценка ошибки: err ≈ |y_1 − y_2| / (2^p − 1)
Порядок:       p ≈ log₂(|e(Δt)| / |e(Δt/2)|)
```

## Часть 7 — Практические решатели

### Python scipy.integrate

```python
from scipy.integrate import solve_ivp

# Нежёсткая задача
sol = solve_ivp(f, [t0, tf], y0, method='RK45',
                rtol=1e-6, atol=1e-9)

# Жёсткая задача
sol = solve_ivp(f, [t0, tf], y0, method='BDF',
                rtol=1e-6, atol=1e-9)

# Высокая точность
sol = solve_ivp(f, [t0, tf], y0, method='DOP853')
```
