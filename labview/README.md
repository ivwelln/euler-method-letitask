# Реализация комплексного 2-шагового Эйлера в LabVIEW

## Состав

| Файл | Назначение |
|------|-----------|
| `complex_euler_mathscript.m` | Код для **MathScript Node** (полностью реализует оба метода) |
| `README.md` | Этот файл — краткое описание |

Подробная пошаговая инструкция по сборке VI находится в файле
**`../Пояснительная_записка_LabVIEW.docx`** (раздел «Сборка VI шаг-за-шагом»).

## Зачем нужен этот скрипт

LabVIEW предоставляет два пути численных расчётов:

1. Соединять примитивные блоки на блок-диаграмме (графический способ).
2. Использовать **MathScript Node** — кусок кода в MATLAB-подобном синтаксисе.

Для метода Эйлера с комплексными шагами выбран вариант №2: один MathScript Node
включает оба метода (классический и 2-шаговый комплексный), все тестовые
уравнения из раздела 2 статьи, точное решение и расчёт нормы погрешности.

## Требования

Нужен LabVIEW с установленным **MathScript Module** (обычно входит в
«Mathematics» при стандартной установке Full Development System).
Тестировалось с LabVIEW 2020 и 2023.
