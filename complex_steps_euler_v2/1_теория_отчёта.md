## Раздел 1 — Фундамент: ОДУ и задача Коши

### Что такое ОДУ

ОДУ = обыкновенное дифференциальное уравнение.
Это уравнение которое связывает функцию и её производную.

```
ẏ(t) = f(t, y(t))
```

Читается: «производная y по времени равна f от t и y».

**Что означает каждый символ:**

```
y(t)   — искомая функция (что ищем)
ẏ(t)   — производная y по времени = скорость изменения y
         Точка над буквой = d/dt (производная по времени)
f(t,y) — правая часть: закон по которому y меняется
t      — время
```

**Примеры f и их смысл:**

```
Уравнение          Смысл
─────────────────────────────────────────────────────
ẏ = y              скорость роста = текущее значение (бактерии)
ẏ = −y             скорость убывания = текущее значение (распад)
ẏ = y²             нелинейный рост (химические реакции)
ẏ = cos(t)         скорость задаётся только временем
ÿ = −y             ускорение = минус позиция (маятник, пружина)
```

**Почему ẏ = y — не странность:**
Это просто описание ситуации: «скорость роста в каждый момент
равна текущей величине». Если сейчас 1000 бактерий — 
размножаются со скоростью 1000 в секунду.
Точное решение: **y(t) = eᵗ · y₀**

---

### Задача Коши (формула 1 отчёта)

```
ẏ(t) = f(t, y(t)),    y(t₀) = y₀          (1)
```

Два кармана знаний:
```
Карман 1:  ẏ(t) = f(t, y(t))    ← ЗАКОН (как меняется)
Карман 2:  y(t₀) = y₀           ← СТАРТ (откуда начинаем)
```

**Аналогия с машиной:**
- f говорит: «твоя скорость зависит от позиции и времени»
- y₀ говорит: «ты стартуешь из точки y₀ в момент t₀»
- Вопрос: где будешь через час?

**Почему нельзя просто проинтегрировать:**
f(t,y) содержит саму y — порочный круг.
Чтобы найти y, нужно знать y
Аналитическая формула существует только для простых f.
Для остального — численные методы.

## Раздел 2 — Явный метод Эйлера (формулы 2 и 3)

### Вывод формулы Эйлера из ряда Тейлора

**Ряд Тейлора** — это способ предсказать значение функции
чуть правее если знаешь значение, скорость, ускорение...

```
y(t + Δt) = y(t) + Δt·ẏ(t) + Δt²/2·ÿ(t) + Δt³/6·⃛y(t) + …    (3)
```

Читается: «значение y немного правее» описывается через
сумму членов с разными степенями шага Δt.

Почему члены становятся маленькими при малом Δt:
```
При Δt = 0.1:
  Δt¹ = 0.1
  Δt² = 0.01     ← в 10 раз меньше
  Δt³ = 0.001    ← в 100 раз меньше
  Δt⁴ = 0.0001   ← в 1000 раз меньше
```

Эйлер берёт только первые два члена (выбрасывает Δt²/2·ÿ и дальше):

**Шаг 1.** Пишем ряд Тейлора:
```
y(t_k + Δt) = y_k + Δt·ẏ_k + Δt²/2·ÿ_k + …
```

**Шаг 2.** Из уравнения ẏ = f(t,y) следует ẏ_k = f(t_k, y_k):
```
y(t_k + Δt) = y_k + Δt·f(t_k, y_k) + Δt²/2·ÿ_k + …
```

**Шаг 3.** Выбрасываем Δt² и дальше (они маленькие):
```
y_{k+1} = y_k + Δt · f(t_k, y_k)          (2)
```

**Что выброшено = ошибка:**
```
Выброшено: Δt²/2·ÿ_k + Δt³/6·⃛y_k + …
Главный член ошибки: Δt²/2·ÿ_k   → локальная ошибка O(Δt²)
```

### Почему порядок первый а не второй

Локальная ошибка за 1 шаг: O(Δt²)
Количество шагов N = T/Δt ~ 1/Δt

```
Глобальная ошибка = N × локальная ошибка
                  = (1/Δt) × O(Δt²)
                  = O(Δt)             ← первый порядок
```

Одна степень Δt «съедается» при суммировании шагов.

### Пример: ẏ = y, y(0) = 1, Δt = 0.5

Поскольку f(t,y) = y, формула упрощается:
```
y_{k+1} = y_k + 0.5 · y_k = 1.5 · y_k
```

Считаем:
```
k=0: t=0.0, y₀=1.000,  точное e⁰·⁰=1.000,  ошибка=0.000
k=1: t=0.5, y₁=1.500,  точное e⁰·⁵=1.649,  ошибка=0.149
k=2: t=1.0, y₂=2.250,  точное e¹·⁰=2.718,  ошибка=0.468
k=3: t=1.5, y₃=3.375,  точное e¹·⁵=4.482,  ошибка=1.107
```

Ошибка нарастает — промахи суммируются.

## Раздел 3 — Идея комплексного пути (раздел 1.3 отчёта)

### Что значит «уйти в комплексную плоскость»

Классический Эйлер движется только вправо по вещественной оси:
```
Im(t)
  ↑
  |
──•──────•──────•──────→ Re(t)
 t_k           t_{k+1}
 шаг Δt вправо
```

Комплексный метод делает зигзаг через мнимую ось:
```
Im(t)
  ↑
  |        y* (промежуточная точка)
  |       /  \
  |      /    \
──•────────────•──→ Re(t)
 t_k          t_{k+1}
 подшаг 1: Δt/2 + iΔt/2 (вправо-вверх)
 подшаг 2: Δt/2 − iΔt/2 (вправо-вниз)
 сумма: Δt (вернулись на вещественную ось)
```

**Зачем зигзаг?**
Потому что он автоматически «захватывает» информацию
о второй производной — без её явного вычисления.
Это даёт 2-й порядок точности.

## Раздел 4 — Вывод двухшагового комплексного метода

### Формула 4: классический Эйлер, два шага по Δt/2

Берём задачу ẏ = y, y(0) = 1.
Делаем два шага по Δt/2 обычным Эйлером:

```
Шаг 1: y₁ = y₀ + (Δt/2)·f(y₀) = 1·(1 + Δt/2)

Шаг 2: y₂ = y₁ + (Δt/2)·f(y₁) = y₁·(1 + Δt/2)
           = (1 + Δt/2)·(1 + Δt/2)
           = (1 + Δt/2)²
```

Раскрываем скобки:
```
y_real(Δt) = (1 + Δt/2)² = 1 + Δt + Δt²/4          (4)
```

### Формула 5: комплексный Эйлер

Берём два комплексных подшага:
```
h₁ = Δt/2 + iΔt/2
h₂ = Δt/2 − iΔt/2
```

```
Подшаг 1: y* = y₀·(1 + h₁) = 1·(1 + Δt/2 + iΔt/2)

Подшаг 2: ỹ  = y*·(1 + h₂)
             = (1 + h₁)·(1 + h₂)
```

Раскрываем произведение:
```
(1 + h₁)(1 + h₂) = 1 + h₁ + h₂ + h₁·h₂
                 = 1 + (h₁+h₂) + h₁·h₂
```

Считаем h₁+h₂:
```
h₁ + h₂ = (Δt/2 + iΔt/2) + (Δt/2 − iΔt/2) = Δt
```

Считаем h₁·h₂ (используем (a+bi)(a-bi) = a²+b²):
```
h₁·h₂ = (Δt/2 + iΔt/2)(Δt/2 − iΔt/2)
       = (Δt/2)² + (Δt/2)²
       = Δt²/4 + Δt²/4
       = Δt²/2
```

Итого:
```
y_complex(Δt) = 1 + Δt + Δt²/2          (5)
```

### Сравнение с точным решением

Точное решение eᵈᵗ раскладывается в ряд:
```
eᵈᵗ = 1 + Δt + Δt²/2 + Δt³/6 + …
```

Сравниваем коэффициент при Δt²:
```
Точное:       коэф. = 1/2
Классический: коэф. = 1/4   ← не совпадает → ошибка в Δt² → 1-й порядок
Комплексный:  коэф. = 1/2   ← совпадает!  → ошибка в Δt³ → 2-й порядок
```

**Вывод:** комплексный зигзаг исправляет коэффициент
с 1/4 на 1/2 и повышает порядок до второго.

## Раздел 5 — Условия порядка (формулы 6 и 7)

### Постановка задачи

Запишем общий двухшаговый метод с неизвестными весами w₁, w₂:
```
подшаг 1 = w₁·Δt
подшаг 2 = w₂·Δt
```

Применяем к ẏ = y, y₀ = 1:
```
y* = y₀·(1 + w₁·Δt) = 1·(1 + w₁·Δt)

y₁ = y*·(1 + w₂·Δt)
   = (1 + w₁·Δt)·(1 + w₂·Δt)
   = 1 + (w₁+w₂)·Δt + w₁w₂·Δt²
```

### Приравниваем к ряду Тейлора

Точное решение: eᵈᵗ = 1 + Δt + Δt²/2 + …

Приравниваем коэффициенты при каждой степени Δt:

```
при Δt¹:   w₁ + w₂ = 1        (условие 1-го порядка)   (6)
при Δt²:   w₁ · w₂ = 1/2      (условие 2-го порядка)   (7)
```

### Решение системы уравнений

Из (6): w₂ = 1 − w₁
Подставляем в (7):
```
w₁·(1 − w₁) = 1/2
w₁ − w₁² = 1/2
w₁² − w₁ + 1/2 = 0
```

Считаем дискриминант (D = b² − 4ac):
```
D = (−1)² − 4·1·(1/2) = 1 − 2 = −1 < 0
```

**D < 0 → вещественных решений НЕТ!**

Это математическое доказательство теоремы 3.1 статьи:
классическим Эйлером с вещественными шагами
2-й порядок получить НЕВОЗМОЖНО.

Берём комплексные решения (√(−1) = i):
```
w₁ = (1 ± √(−1)) / 2 = (1 ± i) / 2

Решение 1: w₁ = 1/2 + i/2,   w₂ = 1 − w₁ = 1/2 − i/2
Решение 2: w₁ = 1/2 − i/2,   w₂ = 1/2 + i/2 (тот же путь, другой порядок)
```

**Проверка:**
```
w₁ + w₂ = (1/2+i/2) + (1/2−i/2) = 1  ✓
w₁ · w₂ = (1/2+i/2)·(1/2−i/2) = 1/4+1/4 = 1/2  ✓
```

## Раздел 6 — Алгоритм макрошага (раздел 1.4.3 отчёта)

```
Дано: t_k, y_k, функция f, шаг Δt
Каноничные веса: w₁ = 1/2 + i/2, w₂ = 1/2 − i/2

1) Первый подшаг (комплексный):
   y* = y_k + (Δt/2 + iΔt/2) · f(t_k, y_k)
   t* = t_k + Δt/2 + iΔt/2   (комплексное «время»)

2) Второй подшаг (комплексный):
   ỹ = y* + (Δt/2 − iΔt/2) · f(t*, y*)

3) Берём вещественную часть:
   y_{k+1} = Re(ỹ)

Стоимость: 2 вычисления f на макрошаг
```

**Честность сравнения:**
Один макрошаг комплексного метода = 2 вычисления f.
Поэтому классическому Эйлеру дают 2 шага по Δt/2.
Тогда оба метода делают одинаковое число вычислений f.

## Раздел 7 — Функция устойчивости (формулы 8 и 9)

### Пробная задача

Для анализа устойчивости применяем метод к задаче:
```
ẏ = λy,   y(0) = y₀    где λ — комплексное число
```

Точное решение: y(t) = y₀·eˡᵗ

Поведение зависит от Re(λ):
```
Re(λ) < 0  → y(t) затухает к нулю
Re(λ) = 0  → y(t) колеблется
Re(λ) > 0  → y(t) растёт до бесконечности
```

### Формула 8: определение функции устойчивости

Применяем любой метод к ẏ = λy. Получаем:
```
y_{k+1} = Φ(z) · y_k,    z = λ·Δt          (8)
```

Φ(z) — функция устойчивости. После N шагов:
```
y_N = Φ(z)ᴺ · y₀
```

Условие устойчивости:
```
|Φ(z)| ≤ 1  →  |Φ(z)|ᴺ не растёт → метод устойчив
|Φ(z)| > 1  →  |Φ(z)|ᴺ → ∞      → метод взрывается
```

### Вывод Φ для классического Эйлера

```
y_{k+1} = y_k + Δt·λ·y_k
        = y_k·(1 + λΔt)
        = y_k·(1 + z)       где z = λΔt

Φ_classic(z) = 1 + z
```

Область устойчивости: |1 + z| ≤ 1
→ круг на комплексной плоскости, центр (−1, 0), радиус 1.

### Вывод Φ для комплексного метода (формула 9)

```
y_{k+1} = y_k·(1 + w₁z)·(1 + w₂z)
        = y_k·(1 + (w₁+w₂)z + w₁w₂·z²)
        = y_k·(1 + z + z²/2)    ← т.к. w₁+w₂=1 и w₁w₂=1/2

Φ_complex(z) = 1 + z + z²/2                          (9)
```

Область устойчивости: |1 + z + z²/2| ≤ 1
→ овал, значительно больше круга классического Эйлера.

### Три сценария из отчёта

```
Сценарий A1: λ = −0.8, Δt = 1.0
  z = −0.8·1.0 = −0.8
  |Φ_classic(−0.8)| = |1−0.8| = 0.20 ≤ 1  ✅
  |Φ_complex(−0.8)| = |1−0.8+0.32| = 0.52 ≤ 1  ✅
  Оба устойчивы.

Сценарий A2: λ = −0.5+1.5i, Δt = 1.0
  z = −0.5+1.5i
  |Φ_classic| = |1+(−0.5+1.5i)| = |0.5+1.5i| = √(0.25+2.25) ≈ 1.58 > 1  ❌
  |Φ_complex| ≈ 0.90 ≤ 1  ✅
  Классический взрывается! Комплексный устойчив.

Сценарий A3: λ = −2.5, Δt = 1.0
  z = −2.5
  |Φ_classic| = |1−2.5| = 1.5 > 1  ❌
  |Φ_complex| = |1−2.5+3.125| = 1.625 > 1  ❌
  Оба неустойчивы.
```

## Раздел 8 — Кольцевой тест round-trip (формула 10)

### Идея

Обычная проверка точности требует знания точного решения.
В реальных задачах точного решения нет.

Кольцевой тест проверяет точность **без точного решения**.

### Алгоритм

```
Шаг 1: Прямой проход
  Интегрируем от t=0 до t=T с шагом +Δt
  Получаем y_forward(T)

Шаг 2: Обратный проход
  Из точки y_forward(T) интегрируем тем же методом
  назад до t=0 с шагом −Δt
  Получаем y_back(0)

Шаг 3: Невязка кольца
  r = |y_back(0) − y₀|
```

Обратный ход = тот же метод, только знак шага меняется:
```
Прямой:   y_{k+1} = y_k + (+Δt) · f(t_k, y_k)
Обратный: y_{k+1} = y_k + (−Δt) · f(t_k, y_k)
```

### Связь с порядком (формула 10)

```
r ~ C · Δtᵖ          (10)
```

На log-log графике: наклон прямой = p = порядок метода.

```
Классический Эйлер:  наклон ≈ 1  → 1-й порядок
Комплексный Эйлер:   наклон ≈ 2  → 2-й порядок
```

```
ÿ = −y         2.41        2.41·10⁻²   ×100
```

## Раздел 9 — Произвольный w₁ (раздел 1.7 отчёта)

### Почему только w₁

w₂ = 1 − w₁ всегда (из условия 1-го порядка w₁+w₂=1).
Одна степень свободы — только w₁.

### Что меняет w₁

**1. Порядок точности** (через w₁·w₂):
```
w₁·w₂ = ½  → 2-й порядок  (только при w₁ = ½±i/2)
w₁·w₂ ≠ ½  → 1-й порядок
```

**2. Форма области устойчивости** (через коэффициент при z²):
```
Φ(z) = 1 + z + w₁w₂·z²

Разный w₁ → разный w₁w₂ → разный коэф. при z² → разная область
```

### Три сценария B из отчёта

```
Сценарий B1: w₁ = ½+i/2  →  w₁w₂=½  →  2-й порядок, стандартный овал
Сценарий B2: w₁ = 1       →  w₁w₂=0  →  1-й порядок, круг Эйлера
Сценарий B3: w₁ = 0.3+0.7i →  w₁w₂≠½  →  1-й порядок, несимм. область
```

### Острый пик (рисунок 8 отчёта)

При Re(w₁) = 0.5, меняем Im(w₁):
```
Im(w₁) = 0.0  →  порядок ≈ 1
Im(w₁) = 0.3  →  порядок ≈ 1
Im(w₁) = 0.5  →  порядок ≈ 2  ← единственная точка!
Im(w₁) = 0.6  →  порядок ≈ 1
Im(w₁) = 1.0  →  порядок ≈ 1
```

Канонический выбор уникален: любое отклонение → потеря 2-го порядка.

## Итоговая шпаргалка всех формул отчёта

```
Задача Коши:     ẏ = f(t,y),  y(t₀)=y₀                   (1)

Явный Эйлер:     y_{k+1} = y_k + Δt·f(t_k,y_k)            (2)
Ряд Тейлора:     y(t+Δt) = y_k + Δt·ẏ_k + Δt²/2·ÿ_k + …  (3)

Классич. (2 шага): 1 + Δt + Δt²/4                          (4)
Компл. (2 подшага): 1 + Δt + Δt²/2                         (5)

Условие 1-го порядка: w₁ + w₂ = 1                          (6)
Условие 2-го порядка: w₁ · w₂ = ½                          (7)
Дискриминант:         D = 1−2 = −1 < 0  → нет вещ. решений

Канонический выбор:
  w₁ = ½+i/2,  w₂ = ½−i/2
  h₁ = Δt/2+iΔt/2,  h₂ = Δt/2−iΔt/2

Функция устойчивости:
  y_{k+1} = Φ(z)·y_k,  z=λΔt                              (8)
  Φ_classic(z) = 1+z
  Φ_complex(z) = 1+z+z²/2                                   (9)
  Условие: |Φ(z)| ≤ 1

Round-trip:
  r = |y_back(0)−y₀| ~ C·Δtᵖ                              (10)
  наклон log-log = порядок p

Произвольный w₁:
  Φ(z) = 1 + z + w₁w₂·z²
  w₁w₂=½ → 2-й порядок И стандартный овал
  w₁w₂≠½ → 1-й порядок И своя форма области
```
