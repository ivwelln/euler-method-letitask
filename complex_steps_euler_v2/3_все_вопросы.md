## Вопрос 1 — Явные и неявные методы. Устойчивость.

### Суть различия

**Явный метод:** y_{k+1} вычисляется явно из уже известных значений.
```
y_{k+1} = y_k + Δt·f(t_k, y_k)    ← всё в правой части уже известно
```

**Неявный метод:** y_{k+1} входит в обе части уравнения.
```
y_{k+1} = y_k + Δt·f(t_{k+1}, y_{k+1})    ← y_{k+1} и слева и справа!
```

### Почему неявный сложнее

f(t_{k+1}, y_{k+1}) зависит от y_{k+1} — нужно решать уравнение.
Для линейного ОДУ ẏ = λy это просто:
```
y_{k+1} = y_k + Δt·λ·y_{k+1}
y_{k+1}·(1 − Δt·λ) = y_k
y_{k+1} = y_k / (1 − Δt·λ)
```

Для нелинейного f нужны итерационные методы (Ньютон).

### Устойчивость

Применяем к пробной задаче ẏ = λy, z = λΔt:

```
Явный Эйлер:   y_{k+1} = y_k·(1+z)
  Φ_expl = 1+z
  |Φ| ≤ 1 при |1+z| ≤ 1 → маленький круг

Неявный Эйлер: y_{k+1} = y_k/(1−z)
  Φ_impl = 1/(1−z)
  |Φ| ≤ 1 при |1−z| ≥ 1 → вся левая полуплоскость!
```

**Почему неявные устойчивее:**
Φ_impl = 1/(1−z): при z → −∞ (очень отрицательный λ),
Φ → 0, то есть решение затухает. Именно так должна вести
себя физически правильная задача с Re(λ)<0.

### Примеры

```
Явные:   Эйлер, RK4, Adams-Bashforth
Неявные: Неявный Эйлер, Adams-Moulton, BDF, Radau
```

### A-устойчивость

Метод A-устойчив если его область устойчивости
содержит всю левую полуплоскость Re(z) < 0.

```
A-устойчив → Re(λ) < 0 → устойчив при ЛЮБОМ Δt
```

Явный Эйлер НЕ A-устойчив.
Неявный Эйлер, AM2, BDF — A-устойчивы.

## Вопрос 2 — Непрерывная и конечно-разностная модели

### Непрерывная модель

Описывает систему через производные. Время непрерывно.
```
ẏ(t) = f(t, y(t))

Время t ∈ ℝ — любое вещественное число
y(t) — функция определённая в каждой точке
Точная математическая модель реальности
```

### Конечно-разностная модель

Заменяем производную разностью соседних значений.
Время дискретно — только в узлах t_k.

```
Прямая разность (→ явный Эйлер):
  ẏ ≈ (y_{k+1} − y_k) / Δt          → 1-й порядок

Обратная разность (→ неявный Эйлер):
  ẏ ≈ (y_k − y_{k-1}) / Δt          → 1-й порядок

Центральная разность:
  ẏ ≈ (y_{k+1} − y_{k-1}) / (2Δt)   → 2-й порядок
```

### Откуда порядки (из ряда Тейлора)

Прямая разность:
```
y_{k+1} = y_k + Δt·ẏ_k + Δt²/2·ÿ_k + …
(y_{k+1} − y_k)/Δt = ẏ_k + Δt/2·ÿ_k + …
                           ↑
                     ошибка O(Δt) → 1-й порядок
```

Центральная разность:
```
y_{k+1} = y_k + Δt·ẏ_k + Δt²/2·ÿ_k + Δt³/6·⃛y_k + …
y_{k-1} = y_k − Δt·ẏ_k + Δt²/2·ÿ_k − Δt³/6·⃛y_k + …
Вычитаем: y_{k+1} − y_{k-1} = 2Δt·ẏ_k + O(Δt³)
(y_{k+1}−y_{k-1})/2Δt = ẏ_k + O(Δt²) → 2-й порядок
```

### Четыре эффекта при переходе

```
1. Погрешность аппроксимации:  O(Δtᵖ) на каждом шаге
   При Δt→0: конечно-разностная → непрерывная (сходимость)

2. Погрешность округления:  ε ≈ 2.2·10⁻¹⁶ (double)
   При слишком маленьком Δt округление перевешивает аппроксимацию!
   Есть оптимальный Δt_opt ≈ ε^(1/p)

3. Изменение устойчивости:
   Непрерывно устойчивая задача ≠ дискретно устойчивая
   ẏ = −y устойчива непрерывно при любом λ<0
   Но явный Эйлер взрывается если Δt > 2/|λ|!

4. Потеря информации:
   Между узлами t_k значения y неизвестны → интерполяция
```

### Теорема Лакса (сходимость)

```
Сходимость = Аппроксимация + Устойчивость

Аппроксимация: метод точно аппроксимирует ОДУ при Δt→0
Устойчивость:  ошибки не нарастают экспоненциально
```

## Вопрос 3 — Симплектические методы

### Проблема

Гамильтоновы системы (маятник, планеты) должны сохранять энергию.
Обычные методы нарушают это:
```
Явный Эйлер:  фазовый объём растёт  → орбита раскручивается
Неявный Эйлер: фазовый объём убывает → орбита схлопывается
```

### Что такое симплектический метод

Метод который сохраняет фазовый объём: det(∂y_{k+1}/∂y_k) = 1.

**Метод Кромера:**
```
v_{k+1} = v_k + Δt·F(x_k)/m
x_{k+1} = x_k + Δt·v_{k+1}   ← НОВАЯ скорость!
```

Отличие от явного Эйлера — одна строчка!
Но это делает метод симплектическим.

**Метод Верле:**
```
x_{k+1} = 2x_k − x_{k-1} + Δt²·a(x_k)
```

Симплектический, 2-й порядок, стандарт молекулярной динамики.

### Нелинейная динамика

Пример: маятник без трения.

```
Явный Эйлер (10000 периодов): амплитуда нарастает до ∞
Неявный Эйлер (10000 периодов): амплитуда затухает до 0
Кромер (10000 периодов): амплитуда постоянна ✓
```

### Связь с Бутусовым

Кромер и Верле — предшественники полунеявных методов Бутусова.
Идея та же: явная часть для одних переменных +
использование «новых» значений для других.

## Вопрос 4 — Явные и неявные РК. Вложенные методы.

### Явные РК

Каждый kᵢ зависит только от предыдущих.
Таблица Бутчера: нижнетреугольная матрица A.

```
k₁ = f(t, y)
k₂ = f(t+c₂Δt, y+a₂₁Δt·k₁)
k₃ = f(t+c₃Δt, y+a₃₁Δt·k₁+a₃₂Δt·k₂)
y_{k+1} = y_k + Δt·(b₁k₁+b₂k₂+b₃k₃)
```

Примеры: RK2, RK4, RK45.

### Неявные РК

kᵢ зависит сам от себя → нужно решать систему уравнений.
Таблица Бутчера: плотная (не нижнетреугольная) матрица A.

```
k₁ = f(t+c₁Δt, y+a₁₁Δt·k₁+a₁₂Δt·k₂)   ← k₁ зависит от k₁ и k₂!
k₂ = f(t+c₂Δt, y+a₂₁Δt·k₁+a₂₂Δt·k₂)
```

Примеры: Radau, Gauss-Legendre. Лучше для жёстких задач.

### Таблица Бутчера

```
Запись метода:    c | A
                  ──┼──
                    | bᵀ

Для RK4:
 0  |  0    0    0    0
1/2 | 1/2   0    0    0
1/2 |  0   1/2   0    0
 1  |  0    0    1    0
────┼──────────────────
    | 1/6  1/3  1/3  1/6

c — моменты времени для kᵢ
A — коэффициенты (нижнетреугольная → явный метод)
b — веса финального усреднения (сумма = 1)
```

### Вложенные методы (embedded RK)

Два метода разного порядка используют ОДНИ И ТЕ ЖЕ kᵢ:

```
y_{k+1}  = y_k + Δt·Σ bᵢkᵢ    ← порядок p
ŷ_{k+1}  = y_k + Δt·Σ b̂ᵢkᵢ   ← порядок p+1

Оценка ошибки: err = |y_{k+1} − ŷ_{k+1}|
→ адаптивное управление шагом!
```

RK45 (Дорманн-Принс): 5 стадий, порядки 4 и 5.
Стандарт в scipy.solve_ivp и MATLAB ode45.

Преимущество: оценка ошибки «бесплатно» — kᵢ уже вычислены.

## Вопрос 5 — Фазовый объём

### Фазовое пространство

Пространство всех состояний системы.
Для системы (q, p): каждая точка = одно состояние.

```
Маятник:
  q = угол отклонения
  p = угловая скорость
  Точка (q,p) = состояние маятника
  Траектория = эволюция во времени
```

### Теорема Лиувилля

Для гамильтоновых систем фазовый объём сохраняется:
```
dV/dt = 0
```

Физический смысл: информация о системе не теряется.

### Влияние числового метода на фазовый объём

```
Якобиан: J = ∂y_{k+1}/∂y_k

det(J) > 1 → объём растёт   → явный Эйлер → орбиты раскручиваются
det(J) = 1 → объём сохраняется → симплектические → физически верно
det(J) < 1 → объём убывает  → неявный Эйлер → орбиты схлопываются
```

### Для явного Эйлера

```
y_{k+1} = (I + Δt·A)·y_k    (для линейной системы)
J = I + Δt·A
det(J) = det(I + Δt·A) ≠ 1 в общем случае
```

### Последствия

На коротких временах все методы дают похожий результат.
На длинных временах (тысячи периодов):
- явный Эйлер: орбита расширяется → физически неверно
- симплектический: орбита постоянна → физически верно

## Вопрос 6 — Адаптивное управление шагом

### Зачем

Фиксированный Δt неэффективен:
- Где решение гладкое → можно идти большим шагом
- Где оно быстро меняется → нужен маленький шаг

### Алгоритм

```
1. Считаем y_{k+1} методом порядка p
2. Считаем ŷ_{k+1} методом порядка p+1 (те же kᵢ)
3. err = ||y_{k+1} − ŷ_{k+1}||

4. Если err > tol: шаг большой
   Δt_new = 0.9 · Δt · (tol/err)^(1/(p+1))
   повторяем шаг

5. Если err < tol/100: шаг маленький (неэффективно)
   Δt_new = 2·Δt  (на следующем шаге)

6. Принимаем шаг если err ≤ tol
```

### Оценка ошибки: методы

```
1. Вложенные методы (RK45):
   Два порядка, одни kᵢ → бесплатно

2. Таблица Рунге:
   Считаем при Δt и Δt/2:
   p ≈ log₂(err(Δt) / err(Δt/2))

3. Шаг и полушаг:
   err ≈ |y(Δt) − y(Δt/2)| / (2^p − 1)
```

### Связь с Бутусовым

Статьи Бутусова math9090950 и algorithms15080275 —
алгоритмы адаптивного шага специально для полунеявных
и композиционных методов.

## Вопрос 7 — IEEE Double и Extended Precision

### Формат IEEE 754 Double (64 бит)

```
Структура: [знак 1 бит][порядок 11 бит][мантисса 52 бита]

Диапазон:  ~10⁻³⁰⁸ до ~10³⁰⁸
Точность:  ~15-16 значащих цифр
Машинное ε ≈ 2.2·10⁻¹⁶

Число = (−1)^знак · 2^порядок · мантисса
```

### Extended Precision (80 бит, x87 FPU)

```
Структура: [знак 1 бит][порядок 15 бит][мантисса 64 бита]

Точность:  ~18-19 значащих цифр
Машинное ε ≈ 1.1·10⁻¹⁹
Используется Intel x87 для промежуточных вычислений
```

### Фиксированная vs плавающая запятая

```
Фиксированная запятая:
  + Предсказуемое поведение
  + Быстрые операции на старых процессорах
  − Маленький диапазон → легко переполнение
  − Использование: встроенные системы, DSP

Плавающая запятая:
  + Огромный диапазон (10⁻³⁰⁸...10³⁰⁸)
  + Относительная точность одинакова для любых чисел
  − Ошибки округления
  − Нет ассоциативности: (a+b)+c ≠ a+(b+c)
  − Использование: научные вычисления
```

### Нет ассоциативности — пример

```python
a = 1e16
b = 1.0
c = -1e16

(a + b) + c = (1e16 + 1) - 1e16 = 0.0   # теряем b!
a + (b + c) = 1e16 + (1 - 1e16) = 0.0   # та же проблема

Правильное вычисление требует сортировки по модулю!
```

## Вопрос 8 — Гамильтоновы системы. Диссипативные и консервативные.

### Гамильтонова система

```
H(p, q) = T(p) + V(q)   ← гамильтониан = полная энергия

Уравнения движения:
  ṗ = −∂H/∂q   (изменение импульса)
  q̇ = +∂H/∂p   (изменение координаты)

Ключевое: dH/dt = 0   ← энергия сохраняется
```

Примеры: маятник без трения, планетарное движение,
квантовые системы (уравнение Шрёдингера).

### Консервативная система

Сохраняется интеграл движения (энергия, импульс, момент).
Фазовые траектории замкнуты.

```
dE/dt = 0    (сохранение энергии)
dp/dt = 0    (при отсутствии внешних сил)
dL/dt = 0    (при центральном поле)
```

### Диссипативная система

Энергия убывает со временем (есть трение, потери).
Фазовые траектории сворачиваются к аттрактору.

```
Маятник с трением: E(t) = E₀·e^{−γt}
RC-цепочка: Q(t) = Q₀·e^{−t/RC}
```

### Для численного моделирования

```
Гамильтоновы → симплектические методы (Верле, Кромер)
              → сохраняют фазовый объём

Диссипативные → обычные методы (RK4, BDF)
              → не сохраняют объём, но это физически верно!
```

Ошибка: применять RK4 к гамильтоновой системе на длинных временах.
RK4 диссипативен → орбиты схлопываются → физически неверно.

## Вопрос 9 — Композиционные и экстраполяционные методы

### Композиционные методы

Берём базовый метод порядка p и комбинируем шаги
с разными коэффициентами → повышаем порядок.

**Ключевая идея: сопряжённый метод**
```
Метод Φ_Δt — один шаг вперёд на Δt
Сопряжённый Φ*_Δt = Φ_{−Δt}⁻¹ — «обратный» метод

Симметричная композиция:
  Φ_Δt/2 ∘ Φ*_Δt/2   ← автоматически чётного порядка!
```

**Метод Стрэнга (2-й порядок):**
```
y(Δt) ≈ Φ_A(Δt/2) ∘ Φ_B(Δt) ∘ Φ_A(Δt/2)

Симметричная схема → 2-й порядок
Базовый метод 1-го порядка → после Стрэнга 2-й порядок
```

**Связь с Бутусовым:**
Статья algorithms15120463 — «Composition of Adjoint Multistep Methods».
Применяют идею симметричной композиции к многошаговым методам.

### Экстраполяционные методы (Ричардсон)

Считаем решение при нескольких шагах:
```
y(h)   = y_exact + C·h^p + O(h^{p+1})
y(h/2) = y_exact + C·(h/2)^p + O(h^{p+1})

Вычитаем:
y_exact ≈ (2^p·y(h/2) − y(h)) / (2^p − 1)    ← порядок вырос!
```

**Статья Бутусова math8060943** — ESIMM:
- База: полунеявный метод 2-го порядка
- Экстраполяция: повышает до произвольно высокого порядка
- Адаптивный шаг (статья math9090950)

## Вопрос 10 — Динамический хаос

### Определение

Детерминированная (нет случайности) система, чувствительная
к начальным условиям.

```
Малое изменение δy₀ → экспоненциальное расхождение:

|δy(t)| ~ |δy₀| · e^{λt}

λ > 0  → хаос  (расходятся)
λ < 0  → устойчивость
λ = 0  → граница хаоса

λ — показатель Ляпунова
```

### Дискретный хаос

В отображениях (разностных уравнениях).

**Логистическое отображение:**
```
x_{n+1} = r·x_n·(1 − x_n)

r < 3:     фиксированная точка или цикл (устойчиво)
r = 3...3.57: каскад удвоений периода
r > 3.57:  хаос
```

### Непрерывный хаос

В ОДУ (нужно минимум 3 уравнения).

**Аттрактор Лоренца:**
```
ẋ = σ(y − x)         (σ = 10)
ẏ = x(ρ − z) − y     (ρ = 28)
ż = xy − βz          (β = 8/3)
```

### Проблема для численных методов

Из-за ошибок округления (~10⁻¹⁶) и λ>0:
```
Через время T_pred ≈ ln(1/ε)/λ ≈ 16·ln(10)/λ ≈ 37/λ

для λ=1: после t≈37 численная траектория
         экспоненциально расходится с истинной!
```

Но статистические свойства (среднее, дисперсия) сохраняются.
→ Численные методы для хаоса: нужен маленький шаг
  и/или методы сохранения структуры.

## Вопрос 11 — Управление симметрией

### Идея

Если физическая система имеет симметрию —
числовой метод должен её сохранять.

**Примеры симметрий:**
```
Временна́я обратимость:  t → −t не меняет уравнение
Сохранение энергии:     dH/dt = 0
Сохранение импульса:    при отсутствии сил
```

### Сопряжённый (adjoint) метод

```
Метод Φ_Δt: один шаг вперёд на Δt
Сопряжённый Φ*_Δt = Φ_{−Δt}⁻¹

Если Φ = Φ*:  метод самосопряжённый (симметричный)
              ↓
              временна́я обратимость сохранена
              порядок автоматически чётный (2, 4, 6...)
              лучше сохраняет квадратичные инварианты
```

### Метод трапеций — пример симметричного метода

```
y_{k+1} = y_k + Δt/2·(f_k + f_{k+1})

Если поменять t → −t:
y_k = y_{k+1} − Δt/2·(f_{k+1} + f_k)

Получаем то же уравнение → метод симметричный!
```

### Практическое значение

```
Несимметричный метод накапливает ошибку, нарушающую
физические законы (энергию, момент) даже на коротких временах.

Симметричный метод сохраняет эти законы значительно лучше
→ адекватнее физической реальности.
```

## Вопрос 12 — Плохо обусловленные задачи. Сингулярность.

### Число обусловленности

```
κ(A) = ||A|| · ||A⁻¹||

κ ≈ 1:    хорошо обусловленная
κ >> 1:   плохо обусловленная

Смысл: если κ = 10⁶, ошибка в данных 10⁻⁹
       может дать ошибку в решении ~10⁻³
```

### Плохо обусловленные ОДУ

Жёсткие системы — пример плохой обусловленности.

```
Число жёсткости = |λ_max|/|λ_min|

λ = (−1000, −1):  κ ≈ 1000  → плохо обусловлена
```

### Сингулярность

Точка где решение или производная → ∞.

**Пример:**
```
ẏ = y²,  y(0) = 1

Точное решение: y(t) = 1/(1−t)

При t→1: y → ∞  ← сингулярность!
```

### Орбитальное моделирование

```
Задача двух тел: F ~ 1/r²

При сближении r→0:
  F → ∞  ← сингулярность!
  Численный метод «взрывается»

Решение — регуляризация:
  Замена переменных убирает сингулярность.
  Например: τ = t·r^(3/2) (закон Кеплера как замена времени)

После регуляризации обычный метод работает нормально.
```

## Вопрос 13 — Ошибки арифметических операций

### Машинное эпсилон

```
ε = наименьшее число такое что 1+ε ≠ 1 в компьютере

Double (64 бит):  ε ≈ 2.2·10⁻¹⁶
Float  (32 бит):  ε ≈ 1.2·10⁻⁷
Extended (80 бит): ε ≈ 1.1·10⁻¹⁹
```

### Основные источники ошибок

**1. Ошибка представления:**
```
1/3 = 0.333...3 (обрезается)
π = 3.14159265358979... (обрезается)
0.1 в двоичной = бесконечная дробь → ошибка!
```

**2. Ошибка округления при операциях:**
```
Каждая операция вносит ошибку ~ε
N независимых операций → ошибка ~√N·ε (случайный блуждание)
N коррелированных → ошибка ~N·ε (накопление)
```

**3. Катастрофическое сокращение:**
```
a = 1.000001, b = 1.000000
a − b = 0.000001   ← потеряли ВСЕ значащие цифры!

Пример в double:
x = 1 + 10⁻¹⁶
x − 1 = 0  ← 10⁻¹⁶ < ε, потеряли!
```

**4. Нет ассоциативности:**
```
(a + b) + c ≠ a + (b + c)  в float!

Следствие: порядок вычислений важен
Правило: складывать числа в порядке возрастания модуля
```

### Влияние на численные методы

```
При уменьшении Δt:
  Ошибка аппроксимации ~ Δtᵖ  → уменьшается
  Ошибка округления ~ ε/Δt    → увеличивается!

Оптимальный шаг: Δt_opt ~ ε^{1/(p+1)}

Для Эйлера (p=1): Δt_opt ~ √ε ≈ 10⁻⁸
При меньшем Δt точность падает из-за округления!
```

## Вопрос 14 — Критические ошибки моделирования из-за округления

### Ракета Patriot (1991)

```
Ситуация: зенитный ракетный комплекс «Патриот»
          в Дахране (Саудовская Аравия)

Проблема: время хранилось в 24-битном регистре
          как целое число в единицах 1/10 секунды

Ошибка представления 1/10 в двоичной:
  1/10 ≈ 0.0001100110011... (периодическая дробь)
  Усечение: погрешность ~9.5·10⁻⁸ сек на каждый отсчёт

За 100 часов работы:
  100 · 3600 · 10 · 9.5·10⁻⁸ = 0.343 сек ошибки

Результат: вычисленное положение ракеты Скад
           отличалось от реального на 687 метров
           → промах → 28 погибших американских солдат

Урок: малая ошибка × много итераций = катастрофа
```

### Ракета Ariane 5 (1996)

```
Ситуация: первый запуск ракеты Ariane 5

Проблема: повторно использовали программу от Ariane 4
          Горизонтальная скорость хранилась как 64-бит float

Ariane 5 летела в 5 раз быстрее Ariane 4:
  Скорость ≈ 32768 (выходит за диапазон 16-бит int!)
  Преобразование float(32768) → int16 → ПЕРЕПОЛНЕНИЕ!
  → исключение → отказ инерциальной системы наведения
  → потеря управления → ракета отклонилась
  → система самоуничтожения сработала

Потери: $370 млн (ракета + научная нагрузка)

Урок: проверяй диапазоны при преобразовании типов
      не переиспользуй ПО без анализа новых условий
```

### Общие уроки

```
1. Ошибки округления накапливаются → особенно в длинных циклах
2. Проверяй диапазоны при преобразовании типов данных
3. Тестируй на граничных значениях
4. Не переиспользуй ПО без анализа совместимости
5. Верифицируй и валидируй критические вычислительные системы
```

## Вопрос 15 — Полуявные методы. Кромер и Верле.

### Метод Верле

```
x_{k+1} = 2x_k − x_{k-1} + Δt²·a(x_k)

Или в форме скоростного Верле:
  x_{k+1} = x_k + Δt·v_k + Δt²/2·a(x_k)
  v_{k+1} = v_k + Δt/2·(a(x_k) + a(x_{k+1}))
```

Особенности:
- Симплектический → сохраняет энергию
- 2-й порядок
- Нужны две точки для старта
- Стандарт молекулярной динамики

### Метод Кромера (симплектический Эйлер)

```
Явный Эйлер (НЕ симплектический):
  v_{k+1} = v_k + Δt·F(x_k)/m
  x_{k+1} = x_k + Δt·v_k         ← СТАРАЯ скорость

Кромер (симплектический):
  v_{k+1} = v_k + Δt·F(x_k)/m
  x_{k+1} = x_k + Δt·v_{k+1}    ← НОВАЯ скорость!
```

Одна строчка → полностью другое поведение!

### Связь с полунеявными методами Бутусова

```
Кромер и Верле — полуявные:
  Явная часть:  v_{k+1} = v_k + Δt·F(x_k)    (вычисляем явно)
  Неявная часть: x_{k+1} = x_k + Δt·v_{k+1}  (x зависит от нового v)

Методы Бутусова обобщают эту идею для многошаговых методов:
  Явная часть (AB):   предсказываем некоторые переменные
  Неявная часть (BDF): корректируем другие

Результат: устойчивее явных И дешевле полностью неявных
```

### Статьи Бутусова

```

math8060943:  ESIMM (экстраполяционный полунеявный)
math9090950:  Адаптивный шаг для ESIMM
math9192463:  Анализ устойчивости полунеявных PC
math10122015: BDF+AB против AM+AB
math10224327: Preference region (зона предпочтения)
```

## Вопрос 16 — Встроенные решатели

### Python scipy.integrate

```python
from scipy.integrate import solve_ivp

def f(t, y):
    return -y   # ẏ = −y

sol = solve_ivp(
    f,
    t_span=[0, 10],    # интервал интегрирования
    y0=[1.0],          # начальное условие
    method='RK45',     # метод
    rtol=1e-6,         # относительная точность
    atol=1e-9,         # абсолютная точность
    dense_output=True  # непрерывное решение
)

print(sol.y)   # решение в узлах
print(sol.t)   # моменты времени
```

Методы:
```
'RK45'   → нежёсткие задачи (стандарт)
'RK23'   → нежёсткие, меньшая точность, быстрее
'DOP853' → нежёсткие, высокая точность (8-й порядок)
'BDF'    → жёсткие задачи
'Radau'  → жёсткие, точнее BDF
'LSODA'  → автоматически определяет жёсткость
```

### MATLAB

```matlab
% Нежёсткая задача
[t, y] = ode45(@f, [0 10], 1);

% Жёсткая задача
[t, y] = ode15s(@f, [0 10], 1);

% С настройками
opts = odeset('RelTol', 1e-6, 'AbsTol', 1e-9, ...
              'MaxStep', 0.1);
[t, y] = ode45(@f, [0 10], 1, opts);
```

Методы:
```
ode45   → RK45,    нежёсткие (стандарт)
ode23   → RK23,    нежёсткие, грубая точность
ode113  → Adams,   нежёсткие, высокая точность
ode15s  → BDF,     жёсткие (стандарт для жёстких)
ode23s  → Розенброк, жёсткие, меньшая точность
ode23t  → Трапеция, умеренно жёсткие
ode23tb → BDF+трапеция, жёсткие
```

### Как выбрать метод

```
Задача нежёсткая          → RK45 / ode45
Задача жёсткая            → BDF / ode15s
Не знаешь жёсткая ли      → LSODA / ode15s
Нужна высокая точность    → DOP853 / ode113
Гамильтонова система      → специальный симплектический
```

### Настройка точности

```
rtol (относительная): |ошибка/решение| < rtol
atol (абсолютная):    |ошибка| < atol

Итоговое условие: |ошибка| < max(rtol·|y|, atol)

Стандарт: rtol=1e-3, atol=1e-6
Высокая:  rtol=1e-6, atol=1e-9
```

## Вопрос 17 — Сходимость. Управление порядком точности.

### Определение сходимости

```
Метод сходится если:
  ||y_num(T) − y_exact(T)|| → 0  при Δt → 0

Порядок сходимости p:
  ошибка ~ C·Δtᵖ
```

### Как измерить порядок: log-log анализ

```
Считаем ошибку при разных Δt:
  (Δt₁, err₁), (Δt₂, err₂), (Δt₃, err₃), ...

Строим log(err) vs log(Δt):
  log(err) = p·log(Δt) + const
  → прямая с наклоном p!

Наклон = порядок метода
```

Именно это — рисунок 4 твоего отчёта.
Классический Эйлер: наклон ≈ 1.
Комплексный: наклон ≈ 2.

### Таблица Рунге

```
Считаем при Δt и Δt/2:
p ≈ log₂(err(Δt) / err(Δt/2))

Пример:
  err(0.1) = 0.05
  err(0.05) = 0.025
  p ≈ log₂(0.05/0.025) = log₂(2) = 1  → 1-й порядок
```

### Управление порядком

```
Как повысить порядок:
  1. Взять метод выше порядком:  Эйлер → RK4
  2. Экстраполяция Ричардсона:   из Δt и Δt/2
  3. Композиционные методы:      комбинация шагов
  4. Комплексный путь:           2-й порядок из Эйлера
  5. Многошаговые AB:            высокий порядок за 1 вычисление f

Компромисс:
  Выше порядок → дороже вычисления (больше kᵢ или история)
  Но при малом Δt высший порядок быстрее сходится
```

## Вопрос 18 — Методы расщепления. Разномасштабные системы.

### Расщепление операторов

```
Сложная задача: ẏ = (A + B)y

Идея: решаем A и B поочерёдно, каждое проще

Первый порядок (Лие):
  y(Δt) ≈ e^{AΔt} · e^{BΔt}

Второй порядок (Стрэнг):
  y(Δt) ≈ e^{AΔt/2} · e^{BΔt} · e^{AΔt/2}
  Симметричная схема → 2-й порядок
```

**Пример: реакция-диффузия**
```
ẏ = D·∇²y + R(y)
     ↑ диффузия  ↑ реакция

Расщепляем:
  Шаг 1: только диффузия (неявный метод — жёсткая часть)
  Шаг 2: только реакция  (явный метод — нежёсткая часть)
```

### Разномасштабные системы (multirate)

```
Быстрые переменные:  λ_fast = −1000  (нужен маленький шаг δt)
Медленные переменные: λ_slow = −1    (хватает большого шага Δt)

Многомасштабный метод:
  Быстрые: M малых шагов δt = Δt/M
  Медленные: 1 большой шаг Δt

Экономия: в M раз меньше вычислений для медленных переменных
```

**Связь с жёсткостью:**
Жёсткость — крайний случай разномасштабности.
BDF справляется через A-устойчивость (большой Δt).
Multirate — через разные шаги для разных переменных.

## Вопрос 19 — Фазовый объём и дискретные операторы

### Дискретный оператор эволюции

```
Численный метод = дискретный оператор Φ_Δt:
  y_{k+1} = Φ_Δt(y_k)

Для линейной системы:
  Φ_Δt = матрица (например I + Δt·A для Эйлера)
```

### Якобиан и фазовый объём

```
J = ∂y_{k+1}/∂y_k   ← матрица Якоби оператора

Объём малой области V в фазовом пространстве после шага:
  V_{k+1} = |det(J)| · V_k

det(J) > 1  → объём РАСТЁТ   → явный Эйлер
det(J) = 1  → объём СОХРАНЯЕТСЯ → симплектические
det(J) < 1  → объём УБЫВАЕТ  → неявный Эйлер
```

### Вычисление det(J) для явного Эйлера

```
y_{k+1} = y_k + Δt·f(y_k)

J = ∂y_{k+1}/∂y_k = I + Δt·(∂f/∂y)

Для линейного f(y) = Ay:
J = I + Δt·A

det(J) = det(I + Δt·A)

При A = diag(λ₁, λ₂, ...):
det(J) = ∏(1 + Δt·λᵢ)

Если все |λᵢ| < 1/Δt:  det(J) < 1 (объём убывает)
Если некоторые λᵢ > 0:  det(J) > 1 (объём растёт)
```

### Практические последствия

```
Консервативная система (планеты, маятник):
  Теория требует det(J)=1 (теорема Лиувилля)
  Явный Эйлер: det(J) ≠ 1 → орбиты деградируют
  Симплектический: det(J) = 1 → орбиты правильные

Диссипативная система (маятник с трением):
  Теория требует det(J) < 1
  Неявный Эйлер: det(J) < 1 → правильно!
  Симплектический не нужен
```
